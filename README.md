# Avito DS Bootcamp 2026 III

## Задача

По поисковому запросу пользователя нужно найти в корпусе из 189212 объявлений услуг до 50 кандидатов, которые дальше уйдут на ранжирование. Качество считается по **Recall@50** (доля объявлений, которые пользователь в итоге выбрал, среди найденных 50).

## Что сделано

- **Пул по локации.** В 83% случаев пользователь выбирает объявление из той же локации, где искал, а многие локации поиска являются регионами без собственных объявлений. По кликам из train считаем в каких локациях реально выбирают объявления для каждой локации поиска и ищем только там. Этот шаг поднял BM25 с 0.44 до 0.79.
- **Несколько источников кандидатов** внутри пула, в среднем около 1200 кандидатов на запрос. BM25 по леммам pymorphy3, TF-IDF по символьным n-граммам, эмбеддинги `deepvk/USER-bge-m3`, поиск внутри двух самых вероятных подкатегорий запроса, лучшие совпадения из других локаций и объявления, выбранные по такому же запросу в train.
- **Кросс-энкодер** `BAAI/bge-reranker-v2-m3` оценивает 100 лучших кандидатов каждого запроса, всего около 1.25 миллиона пар.
- **Ранкер LightGBM LambdaRank** выбирает итоговые 50 объявлений примерно по 50 признакам. Оценки источников и кросс-энкодера, вероятность локации, расстояние, вероятность подкатегории по тексту запроса, соответствие фильтрам поиска, рейтинг, отзывы, цена.
- **Разбор ошибок.** Каждый промах получает причину и гипотезы выбираются по тому, сколько Recall они могут вернуть.

## Стек

- Python 3.10, PyTorch 2.6 (CUDA 12.6)
- sentence-transformers, transformers: `deepvk/USER-bge-m3`, `BAAI/bge-reranker-v2-m3`
- LightGBM (LambdaRank), scikit-learn (BM25 на разреженных матрицах, TF-IDF, наивный Байес)
- pymorphy3 для лемматизации
- pandas, numpy, scipy, pyarrow

Все модели open-source (лицензия Apache-2.0), меньше 1 млрд параметров и работают локально, без внешних API. Веса скачиваются с HuggingFace один раз при первом запуске.

## Как запустить

1. Создать окружение и установить зависимости:
   ```
   conda create -n dl python=3.10
   conda activate dl
   pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu126
   pip install -r requirements.txt
   ```
   Версию PyTorch нужно подобрать под свою видеокарту и драйвер.
2. Скачать данные и положить в папку `dataset/`: `train.parquet`, `benchmark_queries.parquet`, `benchmark_items.parquet`.
3. Открыть `solution.ipynb` в Jupyter Lab и выполнить все ячейки по порядку. Файл ответов `answer.csv` будет создан после выполнения всех ячеек.
